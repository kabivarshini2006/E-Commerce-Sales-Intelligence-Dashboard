# Screenshots

GitHub cannot display an interactive `.pbix` file directly, so
screenshots are recommended.

Export one screenshot for each report page from Power BI Desktop and
save them with these names:

``` text
executive-dashboard.png
product-performance.png
customer-regional-analysis.png
returns-business-insights.png
```

Then add them to this folder.

Recommended README embedding:

``` markdown
## Dashboard Preview

### Executive Dashboard
![Executive Dashboard](screenshots/executive-dashboard.png)

### Product Performance
![Product Performance](screenshots/product-performance.png)

### Customer & Regional Analysis
![Customer & Regional Analysis](screenshots/customer-regional-analysis.png)

### Returns & Business Insights
![Returns & Business Insights](screenshots/returns-business-insights.png)
```

Do not use fabricated or unrelated screenshots. Export the actual report
pages from Power BI Desktop.
